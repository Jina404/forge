# Code of Conduct

This project follows a professional and inclusive collaboration standard.

## Our Pledge

We are committed to a respectful, harassment-free environment.

## Expected behavior

- Be respectful and constructive
- Focus feedback on technical content
- Assume good intent and collaborate professionally

## Unacceptable behavior

- Harassment or discriminatory language
- Personal attacks
- Doxxing or sharing private information

## Enforcement

Report issues to project maintainers through repository channels.
