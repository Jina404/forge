# Forge Documentation

Forge is an open-source autonomous security validation platform built for authorized red-team and application security testing.

This documentation is designed for:

- Security engineers
- Penetration testers
- Researchers
- Platform developers
- Enterprise security teams

## Documentation Map

- Getting started: installation and first campaign run
- Architecture: system design, data flow, and security model
- User guide: campaigns, targets, attack modes, evidence, reporting
- Developer guide: structure, local setup, extending attack modules
- AI agent: planner, reasoning, memory, tool interfaces
- Attack modules: SQLi, XSS, auth, JWT, API, fuzzing
- Deployment: Docker, Kubernetes, cloud, and self-hosting
- Security: responsible disclosure, threat model, permissions
- Examples: practical assessment scenarios
- FAQ: troubleshooting and common operational questions

## Trust and Safety

Forge must only be used against systems you own or are explicitly authorized to test.
See ../SECURITY.md and ./security/safe-usage.md before running assessments.
